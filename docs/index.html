Features
Built for how agents actually work.

Wolf Leader handles the memory layer so your agents spend time building, not re-learning.

🔍

Hybrid search

Keyword and vector search across all project memories. Ask anything — the hub finds the relevant decisions, fixes and notes fast.

📋

Typed memories

Memories have types so your agent knows what it's reading — not just a wall of text.

decision constraint fix goal note problem caveat
⚡

Live project briefs

Each project gets a live summary URL. Paste it into a system prompt and any agent gets up to speed in a single request.

🔒

Fully self-hosted

Your memories stay on your hardware. The hub runs as a Docker stack — Postgres with pgvector, REST API, web UI, and nightly backups.

🌐

MCP + HTTP

Any agent that speaks MCP or plain HTTP can connect. First-class auto-install for Claude Code and Cursor via the desktop wizard.

📦

Session checkpoints

Agents checkpoint progress during the conversation. The same chat updates one record — no duplicates, no noise.

Get started
Up and running in minutes.

The desktop installer handles everything — Docker hub, agent skills, Obsidian, and local Git config.

🍎 Mac

Open the .dmg, drag Wolf Leader to Applications, and launch it. The setup wizard installs the hub and wires up your agents automatically.

Download for Mac

🪟 Windows

Download the release and run start.bat. It builds and runs the installer — no manual setup needed.

Download for Windows

🐳 Docker (manual)

Run the hub directly on a server or NAS without the desktop app.

cp .env.example .env docker compose \ -f docker-compose.postgres.yml \ up -d --build
